# Code of Conduct

## Our Standard

This project is maintained as a professional, technical collaboration space. Participants are expected to be direct, respectful, and focused on improving the workflow system.

Acceptable behavior includes:

- Using clear technical reasoning.
- Giving actionable feedback.
- Disagreeing with ideas without attacking people.
- Respecting privacy and avoiding disclosure of secrets or personal data.
- Helping keep issues and pull requests reproducible and on topic.

Unacceptable behavior includes:

- Harassment, threats, insults, or discriminatory language.
- Publishing private information or credentials.
- Repeated off-topic disruption.
- Misrepresenting test results, security impact, or workflow behavior.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; reject pull requests; or block participants when behavior harms the project or its contributors.

If you need to report a conduct issue, contact the maintainers through the repository's configured private channel. If no private channel is available, open a minimal issue asking for maintainer contact without including sensitive details.
